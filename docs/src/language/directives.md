# 言語ディレクティブ

言語ディレクティブは、スクリプトのTipsや翻訳対象外の項目を`aulua`へ伝えるためのメタデータです。

```text
---$tips
---$script_tips
---$nolang
```

ディレクティブは物理行の先頭へ、小文字で記述します。認識された言語ディレクティブはビルド出力に残りません。

## `---$tips`

`---$tips`は、後続する1つの対応UI項目へTipsを関連付けます。

```lua
---$tips:強さを指定します
---$track:強さ, min = 0, max = 100
local amount = 0
```

Tipsは`Tips.<論理スクリプト名>`セクションへ、対象UIの元の項目名をキーとして出力されます。

- 対応する後続UIがない場合はエラー
- 同じUIに複数のTipsを指定した場合はエラー
- `group`と`separator`には指定できない
- `---$nolang`と併用でき、2つのディレクティブの記述順は問わない
- `.tra2`では使用できない

### 複数行のTips

2行目以降は、`---`と`:`の間へ0個以上の半角スペースを記述します。

```lua
---$tips:1行目
---:2行目
---   :3行目
---$track:強さ, min = 0, max = 100
local amount = 0
```

継続行のインデントには半角スペースを使用してください。継続行を含めたTips本文全体が空の場合はエラーです。開始行の本文が空でも、継続行によって本文が空でなくなる場合は有効です。

`.aul2`へ出力するとき、行間の改行は`\n`へ変換されます。

## `---$script_tips`

`---$script_tips`は、所属する論理スクリプト全体のTipsを指定します。

```lua
---$script_tips:サンプル効果です
```

論理スクリプト内の記述位置は問いませんが、1つの論理スクリプトにつき1件だけ指定できます。複数行の構文は`---$tips`と同じです。

Tipsは`Tips.<論理スクリプト名>`セクションの`effect.name`へ出力されます。

`.tra2`では使用できません。記述した場合はエラーになります。

## `---$nolang`

`---$nolang`は、スクリプト名やUIの一部を通常翻訳の対象から外します。対象はカンマ区切りで複数指定できます。

```lua
---$nolang:name, zero_label
---$track:X, zero_label = 0
local x = 0
```

指定可能な値は次のとおりです。

| 指定値 | 翻訳対象から外す内容 |
| --- | --- |
| `name` | 後続UIまたは`.tra2`の対応する`--param`の項目名 |
| `zero_label` | 後続するトラックバーのゼロ値名称 |
| `options` | 後続する通常UIまたは`.tra2`のリスト選択`--param`にあるすべての選択肢 |
| `option:<選択肢名>` | 後続する通常UIまたは`.tra2`のリスト選択`--param`にある指定した選択肢 |
| `script_name` | 所属する論理スクリプトのスクリプト名 |

例えば、リスト選択の項目名と1つの選択肢を対象外にできます。

```lua
---$nolang:name, option:選択肢2
---$select:選択方法
---選択肢1=1
---選択肢2=2
local mode = 1
```

`script_name`は論理スクリプト内の記述位置を問わず適用され、1つの論理スクリプトで一度だけ指定できます。`script_name`を対象外にしても、`---$script_tips`による`effect.name`には影響しません。

`script_name`以外の指定は後続する1つのUIへ適用されます。複数の`---$nolang`がある場合は指定をまとめて適用します。

`.tra2`の`--param`項目名を対象外にする場合は、対応する`--param`の直前に記述します。

```lua
---$nolang:name
--param:内部用,0
```

リスト選択の`--param`にある項目名や選択肢も、通常UIと同じ指定を利用できます。`.tra2`の`--param`では項目名と選択肢名を`::`より後ろへ短縮しないため、`option:<選択肢名>`にも完全名を指定します。

```lua
---$nolang:name, option:aaa::直線
--param:aaa::種類/select/直線=1/曲線=2/aaa::直線=3,1

---$nolang:options
--param:内部用の種類/select/A=1/B=2,1
```

同名の選択肢が複数ある場合、`option:<選択肢名>`は完全一致するすべての選択肢へ適用します。項目名のない`--param`や構造を認識できない`--param`は`---$nolang`の対象にはできません。

次のような場合はエラーです。

- 未知の値を指定した
- 指定に対応する後続UIがない
- `zero_label`をトラックバー以外へ指定した、またはトラックバーにゼロ値名称がない
- `options`や`option:<選択肢名>`をリスト選択以外へ指定した
- `option:<選択肢名>`に存在しない選択肢を指定した
- `script_name`を同じ論理スクリプト内で複数指定した

## ビルド出力

`---$tips`、`---$script_tips`、`---$nolang`は言語解析用のメタデータであり、ビルド出力から物理行ごと削除されます。TipsとScriptTipsの継続行もまとめて削除されます。

言語ディレクティブの構文が不正な場合はビルドエラーになります。通常のUIディレクティブや未知のディレクティブまで言語メタデータとして削除することはありません。
